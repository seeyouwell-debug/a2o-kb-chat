# a2o 知識庫問答（單頁 HTML）

一個不需要後端的知識庫問答頁。貼上你自己的 Groq API Key，就可以用中文問問題；答案只從頁面內建的知識庫來，沒寫的會直接說沒有。

線上版：**https://seeyouwell-debug.github.io/a2o-kb-chat/**

---

## 這是什麼

- **單一檔案**：只有 `index.html`，沒有建置流程、沒有伺服器、沒有資料庫。
- **自帶檢索**：頁面內建 22 段知識，用關鍵字權重（TF-IDF 概念）挑出最相關的 4 段，再交給模型回答。
- **會標來源**：答案句尾有 `[1]`、`[2]` 編號，可以展開看原文段落。
- **沒答案就說沒答案**：相關度太低時不會呼叫 API，直接告訴你知識庫沒有這段，避免模型自己編。
- **金鑰自己帶**：Key 只存在你這台裝置的瀏覽器（localStorage 或 sessionStorage），不會上傳到任何地方。

## 開始使用

1. 到 [Groq Console](https://console.groq.com/keys) 註冊（免費）並建立一組 API Key，格式像 `gsk_...`。
2. 打開網頁，把 Key 貼進跳出的視窗。
3. 選擇要不要記住：
   - **記住這台裝置** → 存在 `localStorage`，下次打開不用再貼。
   - **只在這次工作階段** → 存在 `sessionStorage`，關掉分頁就消失（公用電腦請選這個）。
4. 直接問問題，例如「修改次數有幾次？」「急件要加多少？」

金鑰可以隨時在右上角「設定」裡清除。

## 本機開啟

因為是純靜態頁，雙擊 `index.html` 就能用。若想用本機伺服器：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000
```

## 換成自己的知識庫

打開 `index.html`，搜尋 `KB+ENGINE START`，會看到一個 `KB` 陣列：

```js
const KB = [
  { cat: "方案與報價", title: "三種合作方案", text: "方案分三種……" },
  { cat: "付款與發票", title: "付款方式",     text: "簽約付 40% 訂金……" }
];
```

- `cat`：左側目錄的分類名稱。
- `title`：段落標題，也是檢索時加權的欄位。
- `text`：段落內容。**一段講一件事**，效果最好。

改完存檔、重新整理就好，不需要重新訓練或上傳。段數沒有硬性上限，但 **30 段以內檢索最準**；資料多時建議每段控制在 150 字以內，並把重點詞放進標題。

## 模型與錯誤處理

預設模型是 `llama-3.3-70b-versatile`，可在「設定」裡改成其他 Groq 模型（清單可自由輸入）。Groq 若下架模型，會出現 404，換一個即可。

頁面會把常見錯誤翻成白話：

| 狀態 | 意思 | 怎麼辦 |
| --- | --- | --- |
| 401 | 金鑰無效或被撤銷 | 重新產生一組 |
| 403 | 金鑰沒有權限 | 確認專案有開放 Chat Completions |
| 404 | 模型不存在 | 換一個模型 |
| 413 | 問題太長 | 縮短問題 |
| 429 | 請求太密集或額度用完 | 等一下，或換金鑰 |
| 5xx | Groq 端出錯 | 稍後再試 |

## 安全與隱私

- 金鑰只存在瀏覽器，不會寫進程式碼、不會送到這個網站的任何地方。
- 問題與檢索到的段落會直接從你的瀏覽器送到 `api.groq.com`。
- **不要把金鑰提交到 Git**。這個專案沒有任何金鑰檔，也不需要 `.env`。
- 若要把頁面公開，任何人打開都得自己貼金鑰，不會用到你的額度。

## 已知限制

- 檢索是關鍵字權重，不是語意向量。問法太口語、或只用單一泛用詞（例如「多少人」）時，可能同時命中多段；這時以標題最接近的那段為主。
- 需要瀏覽器允許跨網域請求（Groq API 支援 CORS）。若在公司網路或某些瀏覽器外掛下失敗，換個瀏覽器測試。
- 沒有對話紀錄資料庫，重新整理就清空。
